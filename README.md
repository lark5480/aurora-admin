# Aurora Admin

Spring Boot 3 + Vue 3 电商后台管理系统。

## 技术栈

- **后端**：Java 21, Spring Boot 3, MyBatis-Plus 3, MySQL 8, Redis, RabbitMQ, Elasticsearch 7
- **前端**：Vue 3, TypeScript, Vite, Pinia, Element Plus, ECharts

## 快速开始

```bash
# 后端
cd backend && mvn spring-boot:run     # 启动在 8080

# 前端
cd frontend && npm install && npm run dev  # 启动在 3001
```

默认管理员账号：`admin` / `admin123`
