# 开发环境搭建指南（Windows 10 + Docker）

> 目标读者：刚接手项目的新同学。按本文操作，一次搞定全部依赖。

---

## 前置条件

| 工具 | 版本建议 | 说明 |
|------|---------|------|
| Windows 10 | 20H2+ | 需要开启 Hyper-V 或使用 WSL 2 |
| Rancher Desktop（推荐）或 Docker Desktop | latest | Rancher Desktop：https://rancherdesktop.io/ （开源免费）<br>Docker Desktop：https://www.docker.com/products/docker-desktop/ （个人免费，企业收费）<br>**注意**：两者使用相同的 Docker 命令，本文档通用 |
| JDK | 21 | 后端构建和运行 |
| Node.js | 18.x 或 20.x LTS | 前端构建 |
| WSL 2 | 内核 5.10+ | 容器运行时会自动安装，也可手动 `wsl --update` |

**安装容器运行时之后**务必确认两件事：

```powershell
# 1. 确认 WSL 2 正常
wsl --status

# 2. 确认 Docker 正常
docker version
docker compose version
```

## 一键启动（推荐）

项目根目录已提供 `docker-compose.yml`，包含全部 6 个服务：

| 服务 | 端口 | 账号/密码 |
|------|------|-----------|
| MySQL 8.0 | 3306 | `root` / `root123` |
| Redis 7 | 6379 | 无密码 |
| RabbitMQ 3 | 5672 / 15672（管理面板） | `admin` / `admin123` |
| Elasticsearch 8.11 | 9200 | 无密码 |
| Spring Boot 后端 | 8080 | — |
| Nginx 前端 | 80 | — |

### 方式 A：只启动中间件（本地开发后端/前端）

```powershell
# 在项目根目录执行
docker compose up mysql redis rabbitmq elasticsearch -d
```

然后在本地分别启动后端和前端：

```powershell
# 终端 1：后端
cd backend
mvn spring-boot:run

# 终端 2：前端
cd frontend
npm run dev
```

前端开发服务器在 `http://localhost:3001`，通过 Vite 代理访问后端。

### 方式 B：全部容器化（演示/部署）

```powershell
# 在项目根目录执行
docker compose up -d
```

首次构建需要几分钟（Maven 编译 + npm build）。完成后：
- 前端：`http://localhost:80`
- 后端 API：`http://localhost:8080`
- RabbitMQ 管理面板：`http://localhost:15672`
- 默认账号：`admin` / `admin123`

### 常用 compose 命令

```powershell
docker compose ps                  # 查看所有服务状态
docker compose logs -f backend     # 跟踪后端日志
docker compose stop                # 停止所有服务（保留数据）
docker compose down                # 停止并移除容器
docker compose down -v             # 停止并清除所有数据卷（慎用）
```

## 中间件与 application-dev.yml 对照

`application-dev.yml` 的所有连接参数都已支持环境变量覆盖，默认值对齐本地开发：

| 配置项 | 环境变量 | 默认值（本地开发） |
|--------|---------|------------------|
| `DB_HOST` | `DB_HOST` | `localhost` |
| `DB_PORT` | `DB_PORT` | `3306` |
| `DB_NAME` | `DB_NAME` | `aurora_admin` |
| `DB_USERNAME` | `DB_USERNAME` | `root` |
| `DB_PASSWORD` | `DB_PASSWORD` | `root123` |
| `REDIS_HOST` | `REDIS_HOST` | `localhost` |
| `REDIS_PORT` | `REDIS_PORT` | `6379` |
| `RABBITMQ_HOST` | `RABBITMQ_HOST` | `localhost` |
| `RABBITMQ_PORT` | `RABBITMQ_PORT` | `5672` |
| `ELASTICSEARCH_URIS` | `ELASTICSEARCH_URIS` | `http://localhost:9200` |

容器化部署时，docker-compose.yml 会自动注入容器名称（如 `mysql`、`redis`）覆盖默认值。

## 常见问题

### Docker 启动报 "Hardware assisted virtualization is not enabled"

进 BIOS 开启 **Intel VT-x** 或 **AMD SVM**，同时确认 Windows 功能里勾选了 Hyper-V。

### 端口冲突

检查端口占用：

```powershell
netstat -ano | findstr :3306    # MySQL
netstat -ano | findstr :6379    # Redis
netstat -ano | findstr :5672    # RabbitMQ
netstat -ano | findstr :9200    # Elasticsearch
```

如果本地已装了某个中间件，可以只启动其他的，比如跳过 MySQL：

```powershell
docker compose up redis rabbitmq elasticsearch -d
```

### WSL 2 内存占用太高

在 `%UserProfile%\.wslconfig` 加：

```ini
[wsl2]
memory=6GB
processors=4
```

然后 `wsl --shutdown` 重启 WSL。

### Docker 镜像拉取慢

Docker Desktop → Settings → Docker Engine，配置国内镜像加速：

```json
{
  "registry-mirrors": [
    "https://mirror.ccs.tencentyun.com",
    "https://docker.mirrors.ustc.edu.cn"
  ]
}
```

### ES 启动报 vm.max_map_count 太低

```powershell
wsl -d docker-desktop sysctl -w vm.max_map_count=262144
```
