# 开发环境搭建指南（Windows 10 + Docker）

> 目标读者：刚接手项目的新同学。按本文操作，一次搞定后端依赖的中间件。

---

## 前置条件

| 工具 | 版本建议 | 说明 |
|------|---------|------|
| Windows 10 | 20H2+ | 需要开启 Hyper-V 或使用 WSL 2 |
| Docker Desktop | 4.x latest | [下载地址](https://www.docker.com/products/docker-desktop/) |
| WSL 2 | 内核 5.10+ | Docker Desktop 会自动安装，也可手动 `wsl --update` |

**安装 Docker Desktop 之后**务必确认两件事：

```powershell
# 1. 确认 WSL 2 正常
wsl --status

# 2. 确认 Docker 正常
docker version
docker-compose version
```

## 快速启动（推荐）

在项目根目录下创建 `docker-compose.yml`，一键启动全部中间件。

> 每个服务更详细的解释见对应的独立文档，这里只给 compose。

```yaml
version: '3.8'

services:
  mysql:
    image: mysql:8.0.33
    container_name: dev-mysql
    restart: unless-stopped
    environment:
      MYSQL_ROOT_PASSWORD: root123
      MYSQL_DATABASE: test_ci
      MYSQL_USER: dev
      MYSQL_PASSWORD: '3!spPY(7rK1p-3L'
    ports:
      - "3306:3306"
    volumes:
      - mysql_data:/var/lib/mysql
      - ../backend/src/main/resources/schema.sql:/docker-entrypoint-initdb.d/01-schema.sql
    command:
      - --character-set-server=utf8mb4
      - --collation-server=utf8mb4_unicode_ci
      - --default-time-zone=+08:00

  redis:
    image: redis:7.0-alpine
    container_name: dev-redis
    restart: unless-stopped
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    command: redis-server --appendonly yes --protected-mode no

  rabbitmq:
    image: rabbitmq:3.12-management-alpine
    container_name: dev-rabbitmq
    restart: unless-stopped
    environment:
      RABBITMQ_DEFAULT_USER: admin
      RABBITMQ_DEFAULT_PASS: admin123
    ports:
      - "5672:5672"
      - "15672:15672"
    volumes:
      - rabbitmq_data:/var/lib/rabbitmq

  elasticsearch:
    image: elasticsearch:7.17.15
    container_name: dev-elasticsearch
    restart: unless-stopped
    environment:
      - discovery.type=single-node
      - "ES_JAVA_OPTS=-Xms512m -Xmx512m"
      - xpack.security.enabled=false
    ports:
      - "9200:9200"
      - "9300:9300"
    volumes:
      - es_data:/usr/share/elasticsearch/data

volumes:
  mysql_data:
  redis_data:
  rabbitmq_data:
  es_data:
```

## 常见问题

### Docker 启动报 "Hardware assisted virtualization is not enabled"

进 BIOS 开启 **Intel VT-x** 或 **AMD SVM**，同时确认 Windows 功能里勾选了 Hyper-V。

### 端口冲突

3306、6379、5672、9200 都是常用端口，如果本地已装了这些服务：

```powershell
# 先查谁在占用
netstat -ano | findstr :3306
```

改 compose 里的 `ports` 映射就行，比如 `"13306:3306"`，然后改 `application-dev.yml` 里对应的 `DB_PORT`。

### WSL 2 内存占用太高

在 `%UserProfile%\.wslconfig` 加：

```ini
[wsl2]
memory=6GB
processors=4
```

然后 `wsl --shutdown` 重启 WSL。

### Docker 镜像拉取慢

Docker Desktop → Settings → Docker Engine，配置国内镜像加速：

```json
{
  "registry-mirrors": [
    "https://mirror.ccs.tencentyun.com",
    "https://docker.mirrors.ustc.edu.cn"
  ]
}
```
