# 前端项目运行指南

---

## 1. 环境要求

| 工具 | 建议版本 | 说明 |
|------|---------|------|
| Node.js | 18.x 或 20.x LTS | [下载地址](https://nodejs.org/zh-cn/) |
| npm | 9.x+（随 Node.js 自带） | 可用 `npm -v` 查看 |

> 项目没有 `.nvmrc`，建议装个 [nvm-windows](https://github.com/coreybutler/nvm-windows) 方便切 Node 版本。

---

## 2. 安装依赖

```powershell
cd frontend
npm install
```

国内网络慢的话配一下镜像：

```powershell
npm config set registry https://registry.npmmirror.com
```

---

## 3. 启动开发服务器

```powershell
npm run dev
```

默认 `http://localhost:3001`。

**运行之前确保后端在 8080 已启动**，因为 Vite 把 `/api`、`/uploads`、`/ws` 全代理到 `http://localhost:8080`（配置在 `vite.config.ts`）。后端没跑的话页面能打开但接口全部 404。

---

## 4. 项目结构速览

```
frontend/src/
  views/          # 页面组件（按业务域分：product/ order/ system/ user/ ...）
  components/     # 公共组件（layout/ notice/）
  stores/         # Pinia 状态（6 个：user message config product order address）
  api/            # 后端接口封装（auth product order user ...）
  router/         # 路由（动态路由 + componentMap）
  utils/          # 工具（request.ts 是 axios 封装，time.ts image.ts）
  services/       # websocket.ts（STOMP/SockJS）
  directives/     # permission.ts（v-permission 按钮鉴权）
  assets/         # theme.css table.css（全局样式）
```

## 6. 代理配置

`vite.config.ts` 的代理规则：

| 前端请求 | 转发到 |
|----------|--------|
| `/api/*` | `http://localhost:8080` |
| `/uploads/*` | `http://localhost:8080` |
| `/ws/*` | `http://localhost:8080`（WebSocket） |

这意味着前端代码里写 `api.get('/user/info')` 实际请求 `http://localhost:3001/api/user/info`，Vite 代理到 `http://localhost:8080/api/user/info`。不用在前端硬编码后端地址。

## 8. 常见问题

### npm install 报错？

```powershell
# 清缓存重试
npm cache clean --force
rm -r node_modules
npm install
```

确认 Node.js 版本 ≥ 18。`node -v` 看一下。

### 页面打开但接口 404？

后端没启动。先跑 `cd backend && mvn spring-boot:run`，确认 8080 端口有进程。

### WebSocket 连不上？

`vite.config.ts` 里 `/ws` 代理配置了 `ws: true`。确认后端 WebSocket 端点 `/ws/message` 可访问。如果浏览器控制台报 SockJS 错误，通常是后端没启。

### TypeScript 报类型错误？

```powershell
npx tsc --noEmit
```

IDE 里红色波浪线多的话，试试重启 VS Code 的 TypeScript Server：`Ctrl+Shift+P` → "TypeScript: Restart TS Server"。

### login 后白屏？

动态路由没注册上。打开浏览器控制台看有没有报错，确认登录接口返回的 `menuTree` 不为空。也可以在 `router/index.ts` 的 `beforeEach` 里打 log 排查。
